# Arapça Öğrenirken — Dijital Bahçe Platformu

Bu proje Ufuk Demir'in kişisel Arapça öğrenim notları, kelime havuzu ve metin tahlillerini içeren **sürtünmesiz (zero-friction)** bir dijital bahçedir.

## Yerel Geliştirme Ortamı

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirici sunucusunu başlatın
npm run dev
```

## Dağıtım (Deploy)
Proje GitHub Pages üzerinde otomatik olarak yayınlanacak şekilde yapılandırılmıştır. `main` dalına yapılan her `git push` işlemi siteyi derleyip yayına alır.
